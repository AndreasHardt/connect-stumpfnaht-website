# Connect – Stumpfnaht

Dieses öffentliche Repository enthält ausschließlich den automatisch erzeugten GitHub-Pages-Webstand der Connect-Fachanwendung zur Bewertung von Stumpfnähten nach DIN EN ISO 5817.

Die maßgebenden Quellen, Regeln, Tests und Build-Skripte liegen im privaten Repository `AndreasHardt/connect.hardt-wiehl`. Funktionale Änderungen werden nicht direkt in diesem Repository gepflegt.
